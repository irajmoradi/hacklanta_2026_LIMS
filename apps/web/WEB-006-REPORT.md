# WEB-006 handoff

Branch: `web/WEB-006`. Implementation commit: `bdf59e2`; final handoff is the subsequent documentation commit. No push or merge.

## Delivered

- Generated heads load through authenticated `/api/assets/` requests, then blob URLs and GLTFLoader. Each head attaches directly to its own cloned rig's `Head` bone with the CV-003 identity transform. Only that clone's `head`, `hair_cap`, `eye`, `eye001`, `eye.001`, and `nose` nodes hide. Original visibility restores on replacement/unmount.
- URL cache is scoped by user and asset kind, with reference-counted source geometry/material/texture disposal after the last consumer leaves. Blob URLs revoke after decoding, including failed loads. Preset material cleanup owns only the preset clone's materials.
- Fallback is GLB, then an authenticated transparent camera-facing head card, then the existing preset face. Missing body models retain the existing procedural village. Auth headers never go to arbitrary manifest URLs; worker heads must be self-contained GLBs from the API asset endpoint.
- Generated head materials receive a gentle 0.28 textured emissive fill; world/body lighting stays cozy. A short cream particle poof and synthesized sound mark the first generated face appearance. Browser autoplay policy suppresses sound before interaction; sound is not replayed later.
- Each villager refreshes its manifest immediately and every 30 seconds, without overlapping polls. Failed requests preserve the current face; older revisions cannot overwrite fresher polled manifests. Requests never launch paid generation.
- Optional `portrait.placeholder` enables the exact hover text `placeholder face (CC0)` on the villager and its label. Absent/false flags show nothing.
- Preserved WEB-005's valid saved-village preference. Without one, complete valid membership dates select the oldest instant (including timezone offsets); missing/invalid dates retain API order. This is the chosen interpretation of ?default village? and preserves existing selection behavior.

## Blockers and proposed contract changes

No implementation blockers. Sound requires prior browser interaction. Missing body rigs retain the procedural preset; generated-head attachment requires the named Head bone. No paid generation was requested.

Propose upstream adoption of CV-003's optional `body.head_glb_url`, `body.head_card_url`, `preset_id: "villager_base"`, plus `portrait.placeholder?: boolean`. `/me.villages[].joined_at` remains optional; exact oldest membership cannot be inferred when dates are absent. Shared contracts remain integrator-owned and unchanged.
