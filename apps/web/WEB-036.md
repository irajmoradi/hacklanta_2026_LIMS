# WEB-036 handoff

Branch: `web/WEB-036`. Implementation milestone: `d555e94`.

Alerts now live beside the profile button, including on mobile. A shared count
includes the current disaster and active challenges/random events; a matching
repair event is counted only once. The ring reflects the lesser of check-in and
neighbor completion, capped at 100%. New alert identities open the dropdown;
ordinary polling/progress updates do not reopen it. The dropdown minimizes after
six seconds, outside pointer/wheel interaction, scene movement keys, or Escape.
It stays above the scene midpoint and scrolls internally. Repair opens check-in;
challenge links open the Mayor panel. These are presentation choices using the
existing API, with no contract changes.

Arena copy uses short fee/pool, review, pre-check, and points labels. Supporting
scoring, AI, and shortcut explanations are available through focus/hover/tap help.
Evidence, organizer terms, review validation, and settlement behavior are preserved.

Changed files: `src/App.tsx`, `src/styles.css`,
`src/components/{DisasterBanner,VillageAlerts,ArenaTip,Colosseum,CompetitionsPanel}.tsx`,
`src/components/colosseum.css`, `tests/{web036,feat014}.spec.ts`,
`playwright.web036.config.ts`, this handoff, and the WEB-036 screenshots.

## Try it

From `apps/web`, install with `bun install --frozen-lockfile`. Start the fixture UI
in PowerShell with `$env:VITE_MOCK='1'; $env:VITE_DEMO_AUTH='1'; bun run dev`.
Choose Iraj, open Debug, expand Trigger disaster, choose outbreak, then close Debug.
Click the top-bar warning badge. Minimize, reopen, wait six seconds, or interact
with the town. Repeat at a mobile viewport. Compete → The seven-day sprint opens
the auditor booth; write a reason and approve/reject, or use J/K and A/R.
