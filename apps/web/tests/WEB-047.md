# WEB-047 handoff

Branch: `web/WEB-047`.
Implementation milestones: `7927e90` (pinned editors and cancelable decor), `1e81835` (pause hidden rendering and compact preview), `29a7f59` (reuse materials during recoloring). Regression tests and baseline tools: `ced4942`.

The Outfit color editor and exterior house editor use a shared modal layout exported from WEB-038's `TryOnPane`. Existing `ShowcasePreview` and house Canvas components supply the preview. Desktop has adjacent preview/controls; phones have a compact fixed preview row. Only controls scroll; Save/Cancel remain visible. Escape cancels the active editor without closing the profile. Exterior house items also preview before applying.

Interior decoration uses the existing room renderer and a scrolling furniture pane. Changes are local drafts until Save. Escape/Cancel discards the arrangement. Draft replay is checked against the newest received room before saving. Existing furniture purchases still happen on the explicit purchase action and are retained when canceling an arrangement; the picker explains this.

The editor pauses the hidden town with the existing interior visibility event. Opening the exterior editor also hides the redundant profile house showcase. Editor previews use one device pixel per CSS pixel to avoid costly rendering on high density displays. Color-only changes retain the existing cosmetic attachments and house geometry, updating owned preview materials in place instead of rebuilding and fitting every wearable.
