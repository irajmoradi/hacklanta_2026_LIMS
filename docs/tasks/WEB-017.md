# WEB-017 — Idle activities + waypoints, pets at the shelter, drag/pan/zoom map

Builds on WEB-016 (home-first schedules in src/scene/layout) and WEB-015 (Portrait in name tags). Keep FIX-003 label rules.
1. **Idle Activity (R-17).** Each user picks an idle activity in My profile → Settings (and from their own card):
   `gardening` → garden patch, `dancing` → festival stage, `reading` → fountain plaza, `home` → outside own house (default),
   `food` → food truck, `walk_pet` → loop along the main road (only selectable if the user has a pet equipped; otherwise disabled
   with a hint). Persist it via the API: add `idle_activity` to the member/profile (new migration `apps/api/migrations/0xx_idle_activity.sql`
   with a CHECK on the 6 values, default `home`), a `PATCH /api/me` (or extend the existing settings endpoint) field, and expose it in the
   village/people payload; document it in packages/contracts/api.md; pytest for it. Waypoint routing: walk from home to the activity
   landmark along road waypoints (no cutting through houses), stay there with an activity-appropriate idle animation/pose
   (bob/sway for dancing, kneel for gardening, sit for reading, etc.—simple transforms are fine), occasionally return home.
   Mayor events/festival_night still override as in WEB-016.
2. **Status badge** on each nametag showing the current state: 🌱 Gardening · 💃 Dancing · 📖 Reading · 🏠 Chilling at Home ·
   🍔 Grabbing Food · 🐕 Walking Pet (show "🚶 Walking" while en route). Compact; must not break label hit testing or overlap.
3. **Pet shelter (R-18).** Populate the pet shelter with several idle pets (reuse existing pet GLBs, e.g. pet_dog/pet_dog_b/any cats),
   small wander/idle animations, inside a fenced yard, so it feels alive.
4. **Map controls (R-19).** Drag to pan (left-drag pans on the ground plane), scroll to zoom toward the cursor, right-drag or
   two-finger to rotate; touch pinch-zoom; clamp to town bounds and sensible zoom limits; keep click-to-select working
   (don't select on drag). Add a small "reset view" button.
Tests: schedule/waypoint unit tests, API pytest, e2e for the settings picker + badge (mock) and the map controls; real-mode
screenshots. All existing tests green. Final report per AGENTS.md.
