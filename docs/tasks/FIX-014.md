# FIX-014 — Profile Overview layout: accomplishments card + Profile settings link

In the profile Overview tab: the Accomplishments card overflows the panel on the right (its 2-column grid is wider than the panel, and the
second item is cut off at the edge), and a lone "Profile settings" text button floats under it, oddly centered with no container. Fix:
- Accomplishments: a responsive grid (`repeat(auto-fill, minmax(180px, 1fr))`) that never exceeds the panel width; each item is a compact row
  (icon + title + date, with the reaction pill aligned right); there are no stray bottom borders.
- Move "Profile settings" into the profile header's action row (a small gear icon button next to the name, own profile only) and remove the floating link.
- Audit every profile tab for horizontal overflow at 1280, 1440, 1920 widths and in the mobile sheet; add a Playwright check that no element inside
  the profile panel exceeds its width.
