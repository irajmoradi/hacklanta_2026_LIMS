# WEB-011 — Big rectangular grid town, driven by data

Owner: "village larger and more rectangle and large; modular so adding upgrades/items/clothes is easy".
Read AGENTS.md, apps/web/src/scene/* (WEB-008 districts, WEB-010 cosmetics), docs/tasks/ARCH-001.md and
docs/tasks/ASSET-003.md (both running in parallel: a registry at `packages/catalog/catalog.json` with building
`placement` hints/levels, and a street/block kit + storefront GLBs: road_straight/corner/t/cross, crosswalk, sidewalk,
streetlight, bus_stop, house_lv4/5, storefront_cafe/records/bakery, town_hall, apartment_small, gym, studio_art, library,
arcade, plaza_tile, hedge_row, upgrade_* — names in that task file). Stay inside src/scene/**.

1. **Layout engine** (`scene/layout/`): deterministic from `village.seed`, a **rectangular town** on a 4 m grid —
   e.g. 9×7 blocks — with a main street + cross streets, sidewalks, crosswalks at intersections, streetlights, a central
   plaza with the Mayor stage/town hall, residential blocks (one 8×8 lot per member, house level → GLB lv1..5, upgrades
   rendered from equipped `upgrade_*`/house items), a commercial strip (storefronts: cafe, records, bakery, arcade, gym,
   art studio, library — assign each villager's "hangout" by their goal tags when obvious, e.g. Lance→gym), the festival
   district (stage, Ferris wheel when unlocked, food trucks), park + lake on the edge. Empty lots show "for sale" signs —
   the town visibly has room to grow as members join. Ground = rectangle with a soft edge, not a disc.
2. **Data-driven**: a `scene/registry.ts` adapter that reads `packages/catalog/dist/catalog.ts` if it exists (import via a
   relative path; feature-detect at build time with a fallback JSON copy inside scene/ if not) — every building/prop
   placement, attach offset and unlock gate comes from data, never hardcoded per item. Adding a new building to the
   registry must place it automatically in a free lot of the right district.
3. **Navigation**: villagers walk along sidewalks (simple grid graph A*), cross at crosswalks, go to their hangout/home/
   plaza by schedule (morning home, afternoon hangout, evening plaza/festival, night home or stage if festival_night).
4. **Camera**: wider default framing for the rectangle, pan bounds, smooth zoom; keep ≥50 fps target (instancing for road
   tiles/props, merged static geometry per block).
Keep existing tests green; add layout determinism + "new registry building gets a lot" tests; screenshots day/night of the
full town (real mode). Final report per AGENTS.md.
