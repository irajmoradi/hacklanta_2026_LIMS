   (ambition, evidence quality, progress → 1–5 each) with an **AI pre-grade suggestion** (LLM reads goal + check-ins +

   (`has_crown`) + XP; everyone who completed gets a star badge. Emergency vote: majority can mark the auditor
   "insufficient" → penalty (recoverable: e.g. pet sad / house downgrade flag) and a random replacement.

   Every action writes activity_events + agent log entries where AI is involved.
