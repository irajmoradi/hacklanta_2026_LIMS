# FEAT-017 — Zoomable Gaussian heads that say silly things

1. **Zoom:** the GaussianHead (LAM) viewer on profiles/showcase gets orbit controls: drag to rotate, scroll/pinch to zoom (clamped), double-click
   to reset, and a ⤢ "big view" modal (a full-screen dark stage, soft key light) to inspect the head up close.
2. **Say something silly:** a 🎤 button next to every villager's Gaussian head:
   - A picker of ~20 built-in silly lines ("I have been training for this moment my whole life.", "Who ate my sandwich?", "I am the
     mayor now.", tongue twisters…) plus "✨ Surprise me" (a short silly line generated by the existing LLM provider from village context,
     max 100 chars, the same moderation as Villager-grams, D-034).
   - **Consent:** for someone else's face/voice it requires their `allow_voice_by_friends`; your own always works. Clear "AI voice" label.
   - Pipeline (reuse what exists): ElevenLabs TTS in that person's cloned voice (or a stock voice if none) → Audio2Expression blendshapes
     from the GPU worker (already used by /avatar/talk_video) → play the audio while driving the **live Gaussian head in the browser** with the
     blendshape stream (the LAM viewer supports expression input; if not, fall back to the rendered MP4 from `/avatar/talk_video`). The idle
     head does subtle blinks/breathing.
   - **Cost control:** cache by (voice_id, text) so built-in lines are generated once per person and replayed for free afterwards; at most
     10 new generations per user per day; only on explicit click.
   - **"Everyone says it":** a fun button in the dashboard that makes all consenting villagers' heads say the same line in sequence (a little
     chorus grid), using cached audio when available.
3. API: `POST /api/heads/{uid}/say {text|preset_id}` → `{audio_url, expr_url|video_url}`; api.md; pytest (consent, cache hit, limits, moderation).
Do NOT trigger world events on the live village. Tests: unit (cache keys, consent), e2e (mock: say → audio + head animates), a webm of a head
saying a line. Final report per AGENTS.md with the generation count used in testing (keep it ≤10).
