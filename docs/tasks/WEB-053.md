# WEB-053 — Mayor scene over the live Mayor's Plaza, with the bobbing camera (R-152, Lance)

currently. I liked the Mayor menu using the Mayor's Plaza tile as a backdrop; it was more immersive. Especially the camera
slightly bobbing up and down, mimicking the bouncing of the mayor."

with a gentle bob synced to the Mayor statue's bounce. WEB-042 (live) replaced that with a full-viewport panel (MayorScene).
Combine them:

  readable sizes), but render it as a translucent overlay (frosted panel, ~70–80% opacity, with the left portraits floating)
  ON TOP of the live 3D scene, zoomed into the Mayor's Plaza, instead of an opaque full-screen card.

  ~1.5–2 s period); respect reduced motion (no bob, a static framing).
- Keep text contrast ≥ AA over the 3D backdrop (frosted blur behind the panel). 390 px: a bottom sheet over the plaza view.
- Esc/back restores the previous camera exactly as today.
