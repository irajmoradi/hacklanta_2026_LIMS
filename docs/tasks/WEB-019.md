# WEB-019 — Control your own villager: WASD + drag-to-ride

1. **WASD / arrow keys** move YOUR villager (current seat) along walkable ground (roads/paths/plazas/yards; never through
   houses, using the routing/nav data from WEB-017/WEB-029). Shift = run. The camera smoothly follows (it can be toggled off with
   C); mouse drag still pans/rotates (map controls stay). While you're controlling it, the idle schedule pauses; 20 s after the
   last input it resumes. Other villagers keep their schedules. Space = wave/emote. Keys are ignored when typing in inputs or
   when a modal is open. A small "🎮 WASD to walk" hint the first time.
2. **Drag-to-ride (R-38):** implement docs/tasks/WEB-022.md exactly (press-hold/drag your own villager onto the Ferris wheel /
   stage / fountain / garden / food truck / shelter / house / study nook / colosseum entrance → activity; the Ferris wheel = ride a
   gondola for 2 loops).
Must not conflict with map drag-pan (pickup only on your villager) or with fullscreen mode (WEB-031: F key). Tests: unit
(collision, key handling), e2e (keyboard moves villager; drag onto wheel → riding), real screenshots/webm. Final report per AGENTS.md.
