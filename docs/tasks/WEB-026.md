# WEB-026 — Make Settings beautiful (and findable)

Screenshot problems in SettingsPanel: the "Sound on" and "Sound volume" labels collide; the browser-default blue range slider sits
inside a heavy dark focus box; a stray unlabeled checkbox floats centered above "Reduced sound"; "Delete my voice" butts against
the next heading; there's no visual grouping or spacing rhythm; the danger zone looks ad hoc.
Redesign the whole Settings panel to match the village design system (styles.css tokens, cozy cards, sage/cream palette):
- **Grouped cards** with icons: Profile (name, idle activity), Villager-grams & voice (friends may use my avatar/voice, receive
  Villager-grams + phone, my voice status + delete), Messages (Mayor texts, roast OK), Sound (on/off toggle switch, a custom-
  styled volume slider with the village accent color, Reduced sound toggle with helper text aligned), Face check, Danger zone
  (a subdued red card, DELETE confirm).
- Custom toggle switches instead of raw checkboxes; labels left, controls right; consistent 12/16/24 px spacing; helper text
  under each control. Accessible: labels bound, focus-visible rings in the accent color (not a black box), keyboard works.
- A sticky Save bar at the bottom when there are unsaved changes.
- **R-51:** a ⚙️ Settings button in the top bar next to Inbox opens this panel. The Villager-gram send screen links to Settings
  when nobody is available to pick.
Also sweep other panels for the same raw-control issues (native sliders, stray checkboxes, cramped headings) and fix them.
Tests: e2e (settings opens from the top bar, toggles save), visual screenshots desktop + mobile, a11y check (axe if available).
