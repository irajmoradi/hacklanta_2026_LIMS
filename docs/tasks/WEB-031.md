# WEB-031 — Left dashboard of minimizable/pop-out widgets, auto-hide on zoom, fullscreen

Builds on WEB-030's layout (docs/refs/r63_hud_drawing.jpg):
1. **Dashboard column (left):** every floating widget lives here as a compact card: Around the Village (feed), A note from the
   Mayor, Your little corner (level/XP/streak/check-in shortcut), plus Gazette headline and this-week goal if present. Lance
   wanted the self-card and the Mayor note gone as *floating* duplicates. They now appear only as compact dashboard widgets, and
   each widget can be hidden/reordered (⋯ menu, persisted in localStorage per seat). Default order: Around the Village, Your
   corner, Mayor note.
2. **Minimized vs. popped-out:** the minimized form shows only the essentials (e.g. Around the Village: last 4 items, one line
   each, no reactions/timestamps). A ⤢ pop-out button opens an enlarged floating panel (draggable, ~2× size) with full detail:
   reactions, exact timestamps, filters, "load more"; the Mayor note shows the full text + history; Your corner shows the XP
   breakdown and streak calendar. The enlarged form has a ⤡ minimize button that animates it back into its dashboard slot. Only
   one popped-out widget at a time (or let them stack; your call, document it). Esc minimizes.
3. **Auto-collapse on zoom:** when the camera zooms in past a threshold (the village fills most of the viewport), the dashboard
   slides off to the left edge, leaving a slim ribbon with an inward arrow (› ) that reopens it on click; zooming back out
   restores it automatically unless the user manually collapsed it. Smooth ≤200 ms transitions; reduced-motion = fade.
4. **Fullscreen/clean view:** a ⛶ button (top bar + keyboard F) hides ALL UI (top bar, dashboard, dock, labels optional) and uses
   the browser Fullscreen API when available. Exit on any key press, or on any meaningful click: clicking a villager exits AND
   opens that villager's profile; clicking a building exits and opens it. A brief hint "Press any key to exit" fades after 2 s.
Keep the HUD no-overlap checks green at 3 viewports; mobile: the dashboard becomes a bottom sheet. Tests: e2e (minimize/pop-out,
auto-collapse on zoom, fullscreen exit via key and via villager click → profile), screenshots. Final report per AGENTS.md.
