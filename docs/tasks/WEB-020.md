# WEB-020 — Let each member pick their house style + colors

WEB-018 picks style + one of 3 preset palettes from a hash of user_id. Make it a choice:
1. API: per-member `house_style` (one of the 6 ASSET-006 styles or null = auto) and `house_colors`
   `{wall, roof, trim, door, accent}` hex (validated `^#[0-9a-f]{6}$`, or null = preset). Migration with distinct suffix
   `_house_colors`; expose on village/people payloads; `PATCH` via the existing me/settings endpoint; pytest; api.md.
2. Web: a **House** editor (from own house click / My profile): style picker (6 thumbnails, locked levels shown), the 3 preset
   palettes as one-tap swatches, plus a per-part color picker (wall/roof/trim/door/accent) with a curated ~16-color cozy palette
   and a custom hex option; live preview on a rotating 3D house; Save. Scene applies colors via named materials immediately
   for everyone (refetch). Mock mode supported.
Tests: unit (color application, validation), e2e (mock editor), real screenshots. Final report per AGENTS.md.
