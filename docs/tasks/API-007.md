# API-007 — Village growth + world state + group-photo onboarding

Read AGENTS.md, apps/api/API-00{3..6}-REPORT.md, apps/api/demo/README.md, docs/cv/cv002.md + workers/gpu/bridge.py
(how avatar_jobs flow; the bridge/worker run live on this machine), Hackathon.pdf (village grows; rewards unlock buildings
like a Pet Shelter that unlocks pets; penalties/craters recoverable). Live API :8010 — test on a temp port. Additive
migration `apps/api/migrations/006_*.sql` (idempotent, no BOM).

1. **Village level**: collective XP (sum of members' lifetime XP + event bonuses) → level thresholds; unlock table
   (e.g. L2 garden, L3 festival lights, L4 pet_shelter → enables pet purchases, L5 ferris_wheel, L6 lake bridge).
   Unlocks are idempotent events in activity_events (`building_unlocked`) + agent log when Mayor announces them.
   Shop items can `requires` an unlocked building (pet_dog_b requires pet_shelter).
2. **World state** in `GET /villages/{vid}`: `world: {level, xp, next_level_xp, unlocked, upcoming, weather, time_of_day}`.
   Weather is set by the Mayor scheduler (validated enum clear|rain|fog|festival_night; at most once per 3h; reason logged)
   and by event penalties (failed event → fog until repaired). Crater repair: completing the repair event removes it.
3. **Group photo**: `POST /villages/{vid}/group-photo` (owner; multipart; consent=true) stores the image and enqueues a
   `segment` avatar_job with input marking it as a group photo (coordinate with bridge input shape — read bridge.py; if the
   bridge needs a change, describe it in your report rather than editing workers/); `GET .../group-photo/{job_id}` returns
   crops (URLs under /api/assets) once the worker wrote them; `POST .../claim {crop_id}` binds a crop to the caller
   (one crop per member, one member per crop) and enqueues that member's head/body pipeline from the crop.
4. Demo story: extend `scripts/demo_story.py` so the demo village is level 4 with festival lights + pet shelter unlocked and
   the ferris wheel "next" (idempotent; `--reset` still only touches the demo village).
Tests (mock LLM/worker) for thresholds, unlock idempotency, weather rate limit, claim uniqueness, membership checks.
Route list for web in packages/contracts/proposals/API-007.md. Final report per AGENTS.md.
