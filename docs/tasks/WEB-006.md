reference). Manifests now may contain `body: {kind:"preset", preset_id:"villager_base", colors, head_glb_url?,
head_card_url?}` (CV-003; CV-004 is baking all 5 demo users right now — some manifests will gain head_glb_url while
you work; poll/refresh manifests every 30 s so heads pop in live).

   optional `portrait.placeholder` boolean; if absent, show nothing.
