# WEB-030 — Profile panel: structure, not a long scroll

Problems: the profile is one long scroll of stacked sections (portrait, showcase, outfit, house, "Owned items" disclosure,
"Earn your next signature" grid, photo items, goals, activity…). Items use generic glyph icons (crown/shirt/ribbon silhouettes,
the "emojis"), even though real 3D thumbnails exist (ASSET-007 `public/thumbs/<id>.png`). "How to earn" is a dead link-looking
label instead of telling you how. Disclosure triangles look like a raw `<details>`.
Redesign:
- **Header:** portrait/Gaussian head, name, level, XP bar, streak, crown/badges in one compact hero.
- **Tabs (sticky):** Overview · Outfit · House · Rewards · Activity. No mega-scroll; each tab fits ~1 viewport on a laptop.
  - Overview: this week's goal + progress, latest check-ins, accomplishments with reactions.
  - Outfit: the Destiny-style showcase (FEAT-003) + owned items grid (equip/colors) using **real thumbnails**.
  - House: house showcase + editor entry (own profile).
  - Rewards: earn-only items as cards with the real thumbnail (locked = desaturated + lock), the actual **requirement text**
    ("Win a weekly crown", "Check in 7 days in a row") with a progress bar where measurable (e.g. streak 3/4 weeks), and source/rarity.
  - Activity: feed for that person.
- Replace all generic glyphs with thumbnails (fall back to a neutral silhouette only when a thumb is missing). No emoji icons in
  item UI.
- Consistent card style, spacing and typography with the WEB-026 Settings redesign; smooth tab transitions (≤150 ms);
  mobile: tabs scroll horizontally.
Tests: e2e (tabs, rewards show requirement text + progress, thumbnails load), screenshots desktop + mobile. Final report per AGENTS.md.
