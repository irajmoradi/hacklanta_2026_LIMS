# WEB-001 — Playable 3D village (browser)

Read `AGENTS.md`, `Hackathon.pdf` intent summary below, and `packages/contracts/api.md` (the API contract — do not edit it).

## Build `apps/web` (bun + Vite + React 18 + TypeScript + @react-three/fiber + @react-three/drei)
1. **Mock API mode** (`VITE_MOCK=1`, default when `/api/health` fails): an in-memory implementation of every
   endpoint in api.md, seeded with village "Hacklanta Crew" and 5 villagers: Iraj, Lance, Stefanny, Maya, Dev
   (varied colors, XP, streaks, goals, ~3 check-ins each, 1 active Mayor challenge). Same TS types as the contract.
   Real mode uses fetch to `/api` (Vite proxy → http://localhost:8000) with `X-Demo-User` header.
2. **Village scene**: procedural layout from `village.seed` (seeded PRNG): grass ground, central plaza with a
   Mayor statue/stage, dirt paths, one house per villager at `house_slot` (house_level 1–3 changes size/roof),
   trees, lanterns, a shop building. Low-poly, warm, cozy, readable. Soft shadows, orbit camera clamped.
   Music-festival flavor welcome (bunting, small stage) — it's the hackathon theme.
3. **Villagers**: chibi characters built from primitives (big head, small body, arms, legs) tinted from
   `avatar.body.colors`; name label; crown if `has_crown`. Each wanders between random waypoints with code-driven
   walk cycle (leg/arm swing, bob) and idle. Each villager has independent materials (recoloring one must not
   change others). Hover highlight; click → profile.
4. **Profile panel** (side sheet): portrait (initials circle now; slot component that will later render
   `photo` / `lam_head`), name, level/XP bar, streak, status line, this week's goal + progress check-ins,
   past goals, recent check-ins. A "▶ Hear them" button calls `POST /voice/lines` and plays the audio if returned.
5. **HUD**: "Play as" villager picker (demo auth), my XP/level, buttons: Check in, Set weekly goal, Shop, Mayor.
   - Check-in modal: status vs progress, text, optional photo upload (evidence endpoint), idempotency key per submit.
   - Goal modal. Shop modal (items, price, owned, requires; buy updates balance). Mayor modal: active events,
     "Pray to the Mayor" text box → shows returned event, "Weekly recap" button.
   - Village feed panel (collapsible) from `/feed`.
6. Optimistic, snappy UI; XP gain toast with a little sound (WebAudio blip OK). Works at 1280×720 and 1920×1080.
