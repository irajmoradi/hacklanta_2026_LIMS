# SFX-001 — Tamagotchi-style humorous sound effects (ElevenLabs Sound Effects)

Hackathon.pdf: "Tamagotchi life living the dream vibes with humorous sound effects maybe". Use the ElevenLabs
**Sound Effects** API (`POST https://api.elevenlabs.io/v1/sound-generation`, header `xi-api-key` from ELEVENLABS_API_KEY
in the root .env; check current docs for params like `text`, `duration_seconds`, `prompt_influence`) to generate a cozy,
cute, consistent SFX pack. **Budget: max 18 API calls total** (log each call to assets/sfx/calls.jsonl with prompt +
duration, no secrets). Keep sounds short (0.3–2.5 s), normalized loudness, trimmed silence (use ffmpeg if available;
otherwise document), mp3 + ogg.

Pack (`apps/web/public/sfx/<name>.mp3`): `checkin_pop`, `xp_ding`, `level_up_fanfare`, `coin_purchase`, `equip_swoosh`,
`crown_ceremony`, `mayor_gong` (Mayor speaks), `prayer_chime`, `event_drumroll`, `evidence_stamp_ok`, `evidence_buzzer_sus`
(funny "suspicious" honk), `pet_bark_happy`, `building_unlock_tada`, `crater_boom_cartoon`, `poke_boing`, `message_blip`,
`night_crickets_loop` (loopable 4–6 s), `festival_crowd_loop` (loopable).
Write `apps/web/public/sfx/manifest.json` ({name, file, duration_ms, loop, volume, description}) and `assets/sfx/README.md`
(prompts, license note: generated with ElevenLabs on the owner's account). Report the call count and a short listening
self-check (file durations/peaks via ffprobe). Final report per AGENTS.md.
