# API-001 — FastAPI backend implementing the contract

Read `AGENTS.md`, `packages/contracts/api.md` and `packages/contracts/schema.sql` (do not edit them).

## Build `apps/api` (Python 3.12, `uv` — run as `python -m uv ...`; FastAPI, psycopg 3 (async pool), pydantic v2, httpx)
- Load env from repo-root `.env` (path `../../.env` relative to apps/api; also works from worktree via env var
  `VILLAGE_ENV_FILE`). Vars: DATABASE_URL, DEMO_AUTH, SERVICE_KEY, AUTH0_DOMAIN, AUTH0_AUDIENCE,
  GOOGLE_API_KEY + GOOGLE_GENAI_USE_VERTEXAI, ELEVENLABS_API_KEY. Never print secrets.
- `scripts/migrate.py` applies `packages/contracts/schema.sql`; `scripts/seed.py` idempotently seeds village
  "Hacklanta Crew" (seed 1337, invite `HACKLANTA`) with Iraj, Lance, Stefanny, Maya, Dev (fixed UUIDs, colors,
  house slots 0–4, a few check-ins/goals/XP, one active Mayor challenge) and a catalog of ~12 items
  (clothing hats/shirts, crown, pet_dog requires house_backyard, house_lv2, house_lv3, decorations).
- Implement every endpoint in api.md under `/api`. Auth dependency: Auth0 RS256 JWT via JWKS (cache) when
  AUTH0_DOMAIN set; `X-Demo-User` when DEMO_AUTH=1. Membership check on every village route (403).
- XP: ledger with unique `source_key`; check-in retry with same idempotency_key → same check_in, xp_awarded 0.
  Shop buy: single transaction, balance check, `requires` check, 409 on failure.
- Every mutation also inserts an `activity_events` row (feed). Feed endpoint renders human text.
- **Mayor** (`app/mayor.py`): google-genai client `genai.Client(vertexai=True, api_key=GOOGLE_API_KEY)`, model
  `gemini-2.5-flash`. Build context from last 7 days of check-ins/goals/events. Structured JSON output
  (response_schema) → validate (kind enum, reward 0–500, penalty in {null,'crater','house_downgrade'}) → insert.
  Recap: funny weekly summary naming each villager. Nudge: short text written *as* the most active villager
  roasting/encouraging the target; if target.roast_ok=false keep it kind. Label as AI. If Gemini fails → canned fallback.
- **Voice** (`app/voice.py`): ElevenLabs TTS `eleven_flash_v2_5`, user's `voice_id` or a default stock voice per
  villager; save mp3 to `data/assets/voice/` (repo-root `data/`), serve via `/api/assets/{key}`.
- Avatars: `GET /avatars/{uid}` returns latest manifest or a default preset manifest built from seed colors.
  `POST /avatars/{uid}/photo` stores the upload under data/assets/uploads and inserts an avatar_jobs row
  (status queued) — the GPU worker (separate task) will consume it. `/health` reports gpu_worker by pinging
  `GPU_WORKER_URL` (default http://localhost:8100/health), "down" if unreachable.
- Internal iMessage routes with `X-Service-Key`.
- CORS for http://localhost:5173.
