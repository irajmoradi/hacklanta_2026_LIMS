# WEB-043 — Procedural variety in the rectangular town (R-113, owner)

Owner: "the trees look so samey, and roads — keep it rectangular but add some procedural differences in roads and trees and
hedges, and change placement of houses and stores." KEEP the rectangular grid (R-78/WEB-033) and stable lot addresses.
Using the existing seeded generator (`scene/layout/town.ts`, deterministic per village seed):
1. **Trees:** several species/silhouettes (reuse existing tree models + scale/rotation/lean/tint jitter, seasonal-ish color
   variation, clusters vs singles, a few flowering/fruit trees), placed by noise (groves, rows along some streets, clearings),
   never on roads/lots/paths.
2. **Roads:** stay rectangular but vary: main avenue vs side lanes (width), a few cobblestone/dirt/brick segments, crosswalks,
   a roundabout or plaza at 1–2 intersections, occasional dead-end lane or alley, lamp posts/benches/signposts sprinkled.
3. **Hedges/fences:** varied hedge heights, gaps, gates, picket/stone fences per lot, flower beds, some lots with no hedge.
4. **Placement:** shuffle which lots hold houses vs stores per seed (stores cluster near the center/main avenue, homes on side
   streets), vary house setbacks/rotation-to-street and yard sizes. Existing addresses/IDs and house ownership must not move for
   the live village if that would break saved data — derive variety from the seed but keep `lot.id → owner` stable (test it).
