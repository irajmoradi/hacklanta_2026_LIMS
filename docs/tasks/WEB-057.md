# WEB-057 — Demo Lab big town: fully rendered houses, well spread-out layout (R-175, owner)

Owner (Iraj) on the merged Demo Lab (WEB-055, `/lab` → Big town): "all the houses should be fully rendered, and frankly the
layout should be better spread out." Today, above 25 villagers the Lab swaps homes for a merged `BuildingFallback` box
(`House simplified` in VillageScene.tsx), and `townLayout` (scene/layout/town.ts) keeps `COLS` fixed and only adds rows, so
100 people make a long, narrow strip.
1. **Layout (sandbox only):** give the town layout an optional, Lab-only shape so large towns grow in both directions:
   roughly square (columns ≈ rows) with the civic core/plaza in the middle, residential neighbourhoods around it, the same
   street/road grid rules, parks/trees/lake/festival spread through it, and natural spacing between houses (no wall of
   identical lots). **The real village's layout and addresses must not change at all** (the existing `townLayout` call path and
   its tests stay byte-identical in output; add a test that proves it).
2. **Fully rendered houses at 100:** every home uses its real house model/level/colors/decor (the same `House` path as the main
   village). Keep it smooth: instance/batch identical house models (InstancedMesh or the existing KitBatch/batchStatic
   machinery), share materials, drop per-house Html labels except hover/selected, and use cheaper shadows or LOD only for
   villagers far away, never for the house appearance. Show the FPS readout; target ≥ 45 FPS at 100 on a typical laptop GPU
   (report the measured number on the runner, honestly, alongside the software-renderer caveat).
3. Camera overview frames the whole square town nicely at 25/50/100 and still lets you zoom into a street.
Tests: layout unit tests (square-ish bounds at 50/100, no overlapping lots, all homes reachable by road, the main village layout
unchanged), Lab Playwright at 1440 px (`ops/remote_run.sh`, AGENTS.md) with screenshots at 25/50/100. Final report per AGENTS.md.
