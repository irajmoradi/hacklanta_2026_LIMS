# CV-002 — Close the loop: API jobs → GPU worker → manifest, and a browser LAM head renderer

apps/api is being edited by API-002 right now — do NOT edit apps/api. Integrate from the worker side instead.

1. **Job bridge** (`workers/gpu/bridge.py`, runs on Windows or WSL): polls the Postgres `avatar_jobs` table
   (DATABASE_URL from root .env; claim with `UPDATE ... SET status='running', lease_until=now()+5min WHERE id=(SELECT ...
   FOR UPDATE SKIP LOCKED)`), maps the stored upload asset key under repo-root `data/assets/`, calls the worker
   (`?wait=true` is fine), then writes a new `avatar_assets` revision with an AvatarManifest:
   body.colors from traits.json (+skin), portrait `{kind:"lam_head", asset_url:<face_512 url>, head_package_url:<zip url>}`
   once the head is ready (portrait `photo` after segmentation), generation states updated; job → done/failed with safe
   error. Asset URLs must be served by the API's `/api/assets/{key}` route (keys relative to data/assets) — check
   apps/api for the exact key format and conform to it. Idempotent on retries. Inserts an `activity_events` row
   `avatar_ready`.
2. **LAM web renderer** (`packages/lam-renderer/`): a small TS module the web app can import:
   `mountLamHead(canvas, {packageUrl, exprUrl?, audio?: HTMLAudioElement})` → renders the avatar.zip (skin.glb +
   offset.ply + animation.glb + vertex_order.json) as the OpenAvatarChat/LAM WebGL renderer does, idle blink/sway
   when silent, and steps Audio2Expression frames by `audio.currentTime` when speaking. Port/adapt the minimal parts of
   the official renderer (check its license; record it). Include a standalone demo page (`packages/lam-renderer/demo/`,
   served by `bunx vite`) that loads `sample_palm`'s head + a voice line's expr json + mp3 (generate one ElevenLabs
   line via the API `POST /voice/lines` on :8010 or directly; ≤2 calls). Fallback: if Gaussian rendering can't work in
   time, render `preview.mp4`-style frames with audio-amplitude jaw flap — say so honestly.
3. Run the bridge end-to-end once: create a job through the API (`POST /api/avatars/{uid}/photo` with X-Demo-User
   13370000-0000-4000-8000-000000000005 "Dev" and a CC0 sample photo, consent=true), see manifest revision appear.
Report timings, screenshots of the renderer demo (save under data/), and exact run commands. Commit on cv/CV-002.
