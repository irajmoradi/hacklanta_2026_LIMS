# WEB-037 — A custom, non-emoji icon language

The dashboard widget badges (a crown in a filled maroon circle, a newspaper glyph in a dark square, etc.) and many UI chips use emoji or
emoji-looking filled badges. Create a small **custom icon set** (inline SVG components, one consistent style: 1.75px rounded strokes, a soft
duotone fill in the widget's accent at 18% opacity, a 20px grid, slightly hand-drawn friendliness) and use it everywhere instead of emoji in UI
chrome: dashboard widget headers (Mayor = a top-hat silhouette, Gazette = a folded paper, Around the Village = a speech bubble with dots, Your corner
= a sprout, Goal = a flag), feed row type icons, idle-activity badges on name tags (gardening trowel, dancing music note, book, house, fork &
spoon, paw, dumbbell, game controller, study lamp), toast kinds, the top-bar alerts badge, and the currency icons only where they're emoji (keep the
custom coin/diamond/SOL). Headers: drop the filled circle/square badge, place the icon inline before the title in the accent color, and make the
titles medium-weight sentence case (no small-caps newspaper gimmick; keep the subtle Gazette serif only in its body).
Keep emoji only in user-generated content and reactions. Tests: unit (icon map covers every activity/feed/toast kind), screenshots at 3
viewports, the HUD overlap checks green. Final report.
