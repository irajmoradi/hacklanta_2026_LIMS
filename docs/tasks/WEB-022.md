# WEB-022 — Drag your villager onto attractions

Only YOUR villager (current seat/user) is draggable: press-and-hold (250 ms) or drag the villager's body to pick it up (it lifts
with a little bounce and a shadow, and the cursor shows grab). While dragging, valid drop targets highlight: Ferris wheel, festival
stage, fountain, garden, food truck, pet shelter, your house. Dropping makes the villager **do the attraction**:
- Ferris wheel: board a gondola and ride it (parent the villager to a gondola that follows the wheel's rotation, ~2 loops),
  then hop off at the base
- Stage: dance; fountain: sit/read; garden: kneel; food truck: eat; shelter: pet a dog; house: chill at home
Dropping anywhere else on the ground walks there. Releasing on nothing returns it. The temporary activity lasts ~2 min, then the
idle-activity schedule (WEB-017) resumes. Must not conflict with map drag-pan (WEB-017): picking up starts only on your
villager. Touch support. Local-only, no API (optionally emit a feed event if an endpoint exists; don't add one).
Tests: unit (drop-target resolution, ride timeline), e2e (mock: drag onto wheel → riding state), real screenshot. Final
report per AGENTS.md.
