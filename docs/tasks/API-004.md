# API-004 — Voice cloning onboarding, voice lip-sync jobs, profile/roles, cost guards

Read AGENTS.md, apps/api/API-00{1,2,3}-REPORT.md, docs/cv/cv002.md (bridge + voice_expr), apps/web/README.md
(WEB-002 "Remaining API gaps"), packages/contracts/proposals/*. Live API on :8010 runs from main — test on a temp port.
Additive migrations only in apps/api/migrations/004_*.sql (idempotent, no BOM).

1. **Voice clone (ElevenLabs IVC)**: `POST /me/voice` multipart (1–3 audio memos, `consent=true` required, store
   consent timestamp + text version) → create an Instant Voice Clone, save `users.voice_id`, `voice_consent=true`.
   `DELETE /me/voice` deletes the ElevenLabs voice + clears fields. Max 1 clone per user; label voice "Village — <name>".
   Tests mock ElevenLabs; one real smoke is NOT allowed (no real person's voice available) — just verify request shape.
2. **Lip-sync for voice lines**: `POST /voice/lines` also enqueues an `avatar_jobs` `voice_expr` job (bridge from CV-002
   already processes it; check workers/gpu/bridge.py for the input shape) and returns `expr_url` (null until ready) +
   `job_id`; `GET /voice/lines/{id}` returns current `audio_url`, `expr_url`. Mayor nudges/recaps with voice also get
   expr jobs when the target has a lam_head.
3. **Profile + roles**: `PATCH /me` (display_name, phone_e164 validated E.164, roast_ok, agent_msgs_ok); `/me` returns
   per-village `role` and `is_auditor_this_week`.
4. **Photos**: resize uploads > 10 MiB / > 4096 px server-side (Pillow) instead of rejecting.
5. **Cost guards**: scheduler skips villages with no human activity in 48h and villages named `QA-*`; global
   per-hour LLM call budget (`LLM_MAX_CALLS_PER_HOUR`, default 60) with agent-log entry when throttled.
6. **Weekly recap narration**: optional `voice=true` on recap → ElevenLabs line in the Mayor's stock voice.
Tests for all (mock providers); keep all existing tests green. Final report per AGENTS.md + web-facing route list in
packages/contracts/proposals/API-004.md.
