# API-010 — Plan gaps: villager messages, bribe the Mayor, live presence, full self-deletion

Read docs/PLAN_COVERAGE.md (❌ rows), Hackathon.pdf, AGENTS.md, apps/api/API-00{4,8}-REPORT.md. API-009 (mayor.py,
scheduler.py, newspaper/memory) and ARCH-001 (catalog_registry, migration 008) run in parallel — don't touch their files;
use migration 010 (additive, idempotent, no BOM). Live API :8010 — test on a temp port.

1. **Villager ↔ villager messages**: `POST /villages/{vid}/messages {to_user_id, text, kind: "message"|"poke"|"cheer"}`,
   inbox/outbox list, unread counts, mark read; membership-checked; rate limited; pokes/cheers also land in the feed.
   Optional iMessage relay: if the recipient opted into agent messages and has a phone, enqueue to mayor_outbox labeled
   "via Village from <name>".
2. **Bribe the Mayor**: `POST /villages/{vid}/mayor/bribe {xp, wish}` — spend XP (ledger, atomic) to raise the odds/size of a
   requested event; stores the bribe; the Mayor scheduler (API-009) can read pending bribes from a `mayor_bribes` table —
   expose a pure function `pending_bribes(conn, vid)` in bribes.py for it. Funny AI-flavored receipt text is generated
   later; for now a template. Record SOL bribes as intents only (`currency: "xp"|"sol_intent"`).
3. **Live presence**: `GET /villages/{vid}/presence/stream` (SSE) + `POST .../presence/heartbeat {x,z,activity}` — in-memory
   per-process presence (TTL 30 s), broadcast who's online + their position/activity; membership-checked.
4. **Full self-deletion**: `DELETE /me` (requires `{"confirm": "DELETE"}`): removes the user's memberships, check-ins,
   evidence files, avatar assets/files, voice clone (ElevenLabs delete via existing voice adapter), messages, outbox rows;
   transfers village ownership to the longest-tenured member or deletes a now-empty village; writes an audit row without PII.
Tests for all (mock providers). Route list → packages/contracts/proposals/API-010.md. Final report per AGENTS.md.
