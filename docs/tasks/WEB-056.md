# WEB-056 — Demo Lab: onboarding + interactive avatar/mesh pipeline demos (R-169, owner)

Owner (Iraj), for the judges tomorrow: a hidden Demo Lab (separate from the main village) that shows **the onboarding**
(making a village from scratch, and joining an already built one) and **the exact image → avatar and object → mesh creation
steps in a fairly interactive way**. WEB-055 builds the Lab shell at the same time: route `/lab`, the scene registry
`src/lab/scenes.ts` (`LAB_SCENES: {id,title,blurb,load}[]`, with placeholder ids `onboarding` and `pipeline`), and an
in-memory sandbox. **Only touch your two folders plus your two entries in `scenes.ts`** (point `load` at
`./onboarding/OnboardingDemo` and `./pipeline/PipelineDemo`, each a default-exported React component). If scenes.ts doesn't
exist yet on your branch, create it with exactly that shape; the integrator will merge.

1. **Onboarding demo (sandbox, no server writes):** two tracks with a stepper and "Next" buttons:
   a. **Create a village from scratch:** name + invite link → take/upload a photo (use a bundled sample image; a real upload
      only previews locally) → consent screen (face, voice) → your avatar appears → first goal → first check-in → the empty
      village at level 1. Reuse the real onboarding components where possible (read `src/components/` onboarding/settings/
      goal/check-in code), wrapped so every API call goes to an in-memory mock.
   b. **Join an existing village:** open invite → pick your seat/photo → land in a populated village with neighbors greeting you.
2. **Pipeline demo (interactive, cached artifacts only, NO new generation, NO GPU/ElevenLabs calls):**
   **Image → avatar:** Iraj's consented photo (D-041; only his) → SAM 3 mask overlay with an opacity slider and a toggle for the
   person/hair/clothes regions → extracted traits (skin/hair/shirt swatches) → the stylized villager tinted from them, rotating
   → the LAM 3D Gaussian-splat head (reuse the existing head viewer; drag to rotate) → talking head playing a cached line.
   **Object → mesh:** an item photo/prompt → segmentation → the Hunyuan3D GLB on a turntable with wireframe/normals toggles
   and the final in-game prop. Use existing cached assets: fetch read-only with the Iraj demo-seat header where needed, or
   copy small static copies into `apps/web/public/lab/` (no other people's faces/voices; keep each file small; total ≤ 15 MB).
   Each step labeled with the model and where it runs (SAM 3 · LAM · Audio2Expression · ElevenLabs · Hunyuan3D, Modal GPU),
   with a timing chip from real measured numbers (docs/ or ops/reports), and Prev/Next plus autoplay.
Tests: unit tests (the demos never call POST/PUT/DELETE; steps advance), Playwright at 1440 px in mock mode via
`ops/remote_run.sh` (AGENTS.md) with screenshots of every step. Final report per AGENTS.md.
