# WEB-034 — One polished toast/notification system

Today various flows render ad-hoc pills ("Rebuilt! Everyone is home", purchase/check-in confirmations, errors, "Reconnecting…") with
inconsistent styling, and they overlap open panels (e.g. on top of the profile header). Build a single `useToast()` system and migrate
EVERY ad-hoc toast/pill/banner-like confirmation to it:
- Placement: top-center under the top bar (never over the dashboard, the dock, or an open side panel; shift left of the profile panel
  when it's open). Stack up to 3, newest on top, with a subtle spring in/out (≤180 ms).
- Design: compact card (radius 14, soft shadow, cream surface) with a leading icon/thumbnail by kind (success ✓, reward 🪙/💎 with an
  amount, event/disaster with its icon, error, info), title + optional one-line detail, optional action button ("View", "Undo",
  "Retry"), progress bar for auto-dismiss (4 s; errors persist until dismissed), close ×. No sparkle-character decorations.
- Celebrations (repair done, level-up, crown) use a richer "moment" variant: a centered card with an illustration for 2.5 s +
  confetti (coordinate with VFX-001's celebration particles, but the card belongs to this system).
- Accessible: aria-live polite/assertive, focusable actions, reduced motion.
Tests: unit (queue/stack/dismiss), e2e (toast never intersects open panels at 3 viewports), screenshots of each kind. Final report.
