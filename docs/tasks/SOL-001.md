# SOL-001 — Village weekly pot: Anchor program (build + local tests only)

Product intent (Hackathon.pdf): friends put SOL into a weekly goal pot; a randomly chosen auditor (who sits out)
grades; winner(s) take the pot minus an auditor fee agreed at creation. Devnet only.

Toolchain lives in **WSL Ubuntu-24.04** (user iraj): solana-cli 4.1.2, anchor-cli 1.2.1 (avm), SBF platform tools
installed, wallet ~/.config/solana/id.json (devnet). Run WSL commands by writing a .sh file inside your worktree and
invoking `MSYS_NO_PATHCONV=1 wsl.exe -d Ubuntu-24.04 bash /mnt/c/Users/mourn/Downloads/hl-sol/<path>.sh`
(inline `bash -lc '...'` quoting breaks from Git Bash). Put `$HOME/.cargo/bin` and
`$HOME/.local/share/solana/install/active_release/bin` on PATH in those scripts. Prefix anchor/surfpool with NO_DNA=1.
protobuf-compiler is NOT installed (no sudo) — avoid deps that need protoc.

Program `village_pot` (Anchor 1.2.x) in `programs/village-pot/`:
- `create_pot(week_id, entry_lamports, auditor, auditor_fee_bps <= 2000, deadline)` -> PDA ["pot", creator, week_id].
- `join` transfers the entry into a vault PDA and records the participant (max 8); the auditor cannot join.
- `settle(winners)` auditor only, after deadline: pays auditor fee, splits remainder equally among winners (must be
  participants), marks settled. `refund_all` if not settled 72h after deadline (anyone may call).
- Checked math, rent-exempt vault handling, no double settle, explicit account constraints.
Tests (Anchor TS or LiteSVM): happy path, auditor cannot join, non-auditor settle rejected, double settle rejected,
refund path, fee bounds. `anchor build` and tests must pass locally.
